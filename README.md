# El Diario de la Diáspora 📰

Portal de noticias digital para la comunidad hispana e internacional, desarrollado con **Next.js 15**, **React**, **Tailwind CSS**, y **Firebase**.

## 🚀 Inicio Rápido (Instrucciones para Colaboradores)

Para correr el proyecto en tu computadora local:

### 1. Clonar el repositorio
```bash
git clone https://github.com/vociferaloagencia-create/el-diario-de-la-diaspora.git
cd el-diario-de-la-diaspora
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Configurar variables de entorno (Opcional en modo demo)
Copia la plantilla `.env.example` a `.env.local`:
```bash
cp .env.example .env.local
```
*(El proyecto cuenta con un modo seguro aislado para trabajar localmente de inmediato con datos de prueba sin necesidad de credenciales obligatorias).*

### 4. Iniciar el servidor de desarrollo
```bash
npm run dev
```

Abre en tu navegador: [http://localhost:9005](http://localhost:9005) (o el puerto asignado).

## 🛠️ Tecnologías Utilizadas
- **Next.js 15** (App Router & Turbopack)
- **React 18**
- **Tailwind CSS**
- **Lucide Icons**
- **TypeScript**
