# **App Name**: NewsFlash

## Core Features:

- Article Submission: Allow users to submit news articles with a title, content, and optional image.
- Article Display: Display articles in a chronological order, with options to sort by category.
- Image Storage: Store and serve uploaded images using Firebase Storage.
- Category Filters: Allow users to filter articles by predefined categories (e.g., Politics, Sports, Technology).
- Firestore Integration: Utilize Firestore as the database to store article data, including metadata and content.

## Style Guidelines:

- Primary color: Deep blue (#293B5F) to convey trust and authority.
- Background color: Light gray (#E2E2E2) to provide a neutral backdrop for content.
- Accent color: Soft teal (#73A580) to highlight interactive elements.
- Body font: 'Inter', a sans-serif font for clean and readable article text.
- Headline font: 'Space Grotesk', a sans-serif font for clear, modern headlines.
- Use simple, outline-style icons for categories and navigation.
- Implement a clean, card-based layout for article previews.
